# GitHub-style account UI demo

A small front-end practice project that recreates the general layout of GitHub-style sign-in and registration pages. It is intended for learning HTML and CSS and is not an official GitHub page.

## Features

- Responsive sign-in card and split-panel registration page
- Standalone sign-in and registration pages
- Slovenian labels and interface text
- Clearly marked demo page
- Client-side demo validation only; credentials are not stored or transmitted

## Project files

- `login.html` — sign-in page and demo sign-in behavior
- `register.html` — standalone account registration page
- `CSS/style.css` — layout, colors, typography, form styling, and responsive page presentation

## Run locally

No build tools or dependencies are required. Open `index.html` in a web browser. Keep the `CSS` folder next to the HTML file so the stylesheet loads correctly.

## Safety note

This is a visual learning example only. It is not affiliated with GitHub and must not be used to collect real login details.
