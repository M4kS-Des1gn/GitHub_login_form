# GitHub-style login UI demo

A small front-end practice project that recreates the general layout of a GitHub-style sign-in page. It is intended for learning HTML and CSS and is not an official GitHub page.

## Features

- Responsive, centered sign-in card
- Login and registration preview toggle
- Slovenian labels and interface text
- Clearly marked demo page
- Disabled input fields: the page does not collect, store, or transmit credentials

## Project files

- `index.html` — page structure, demo content, and the small script that switches between the login and registration previews
- `CSS/style.css` — layout, colors, typography, form styling, and responsive page presentation

## Run locally

No build tools or dependencies are required. Open `index.html` in a web browser. Keep the `CSS` folder next to the HTML file so the stylesheet loads correctly.

## Safety note

This is a visual learning example only. It is not affiliated with GitHub and must not be used to collect real login details.
